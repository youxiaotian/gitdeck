# `public/` 前端说明

## 文件

- `index.html`：静态骨架、图标 symbol、弹窗层和无障碍标签。
- `styles.css`：布局、组件样式、状态颜色和响应式规则。
- `app.js`：全部前端状态、API 调用、渲染、事件、弹窗和提示。

## 规则

- 不使用框架和运行时 npm 依赖。
- 前端状态集中放在 `app.js` 顶部的 `state`。
- 动态 HTML 必须转义，或直接构建 DOM。
- 新控件优先使用 `data-*` 事件委托。
- 破坏性操作必须复用统一确认流程。
- 布局变化必须检查桌面和窄屏。
- 状态、DOM 或交互变化要更新 `docs/UI-MAP.md`。

## 状态颜色

- 绿色：新增/未跟踪。
- 红色：删除/破坏性。
- 蓝色：修改/重命名。
- 深红：冲突。
