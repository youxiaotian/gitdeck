## 2026-11-03 - 仓库拖拽排序与会话自动恢复

- 目标：允许自定义仓库顺序，并修复服务重启后的旧令牌错误。
- 改动：
  - 仓库行支持原生拖拽排序；
  - 排序写入 `repositories.json` 的仓库相对顺序；
  - 新增 `/api/repositories/reorder`；
  - 拖拽后抑制误点击；
  - 右键菜单移除失效的“打开终端”和“打开目录”；
  - API 返回 403 时自动刷新页面获取新会话令牌。
- 验证：
  - 排序接口测试验证顺序保存；
  - 浏览器拖拽和刷新后顺序保留；
  - 令牌失效自动刷新只执行一次，避免循环。

## 2026-10-30 - 修复 start.cmd 无法双击启动

- 验证：

  - 浏览器地址返回 HTTP 200。
