# 路线图与已知不足

## 当前范围

- Windows 优先的本地 Git 工作台。
- 多工作区和多仓库总览。
- 内联 Diff 和文本编辑器。
- 暂存、选中提交、还原、抓取、快进拉取、推送。
- 分支作者/时间、搜索、安全批量删除和可选远程删除。
- Stash 创建和恢复。
- 本地目录扫描和内置目录选择器。

## 近期候选

### 仓库健康总览

- 工作区级“需要处理”摘要；
- 长期未更新的分支；
- 上游已删除的本地分支；
- 大量未跟踪目录提示；
- 远端认证状态提示。

### 分支管理

- 按时间、名称、当前分支排序；
- 只看当前分支；
- 分支差异摘要；
- 只删除已合并分支预览；
- 多个远端匹配时允许明确选择目标。

### 文件工作流

- 语法高亮；
- 编辑器行号；
- 文件选择范围；
- 部分行暂存；
- 在变更目录树中搜索；
- 单文件历史。

### 提交流程

- 提交模板和校验；
- 恢复上一条提交说明；
- Amend 前预览；
- 提交后可选推送；
- 使用本机 Git 配置的签名提交。

### 导航和体验

- 工作区拖拽排序；
- 仓库拖拽到其他工作区；
- 固定常用仓库；
- 键盘命令面板；
- 按工作区记忆筛选条件。

## 当前明确不做

- 完整合并冲突编辑器。
- 交互式 rebase UI。
- 子模块专页。
- GitHub/GitLab/Azure DevOps API 集成。
- 工作区云同步。
- 自动保存 Git 凭据。

## 可扩展性风险

超大仓库或大量仓库可能出现：

- 变更目录树 DOM 过多；
- 分支列表过长；
- 多仓库状态请求频繁；
- Diff DOM 过大。

候选优化：

- 虚拟列表；
- 服务端分页和筛选；
- 文件夹懒加载；
- 请求合并；
- 手动刷新的交互优化（不引入后台定时轮询）。
